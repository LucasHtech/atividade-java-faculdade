# Atividade de Entrega — Algoritmos e Programação (Java)

Repositório acadêmico contendo a resolução de 12 exercícios práticos de lógica de programação, manipulação de entrada de dados no console (`Scanner`) e estruturas condicionais em Java.

---

## 🎯 Conceitos Aplicados
- Entrada e saída de dados via terminal (`Scanner` e `System.out`)
- Tipos de dados primitivos (`int`, `double`, `boolean`) e objetos (`String`)
- Operadores aritméticos e relacionais
- Estruturas de controle de fluxo e decisão (`if`, `else if`, `else`)

---

## 📁 Estrutura dos Exercícios

| Exercício | Diretório | Descrição / Objetivo |
| :--- | :--- | :--- |
| **01** | `exercicio-01-cadastro-simples` | Leitura e exibição de dados cadastrais no console |
| **02** | `exercicio-02-conversor-temperatura` | Conversão de graus Celsius para Fahrenheit com operações matemáticas |
| **03** | `exercicio-03-area-perimetro` | Cálculo geométrico de área e perímetro |
| **04** | `exercicio-04-salario` | Cálculo de salário bruto baseado em valor/hora e horas trabalhadas |
| **05** | `exercicio-05-maioridade` | Estrutura condicional para classificação de faixa etária/maioridade |
| **06** | `exercicio-06-situacao-academica` | Cálculo de média e determinação de aprovação ou recuperação |
| **07** | `exercicio-07-positivo-negativo` | Verificação de sinal numérico (positivo, negativo ou zero) |
| **08** | `exercicio-08-desconto` | Aplicação de desconto percentual condicional com base no valor |
| **09** | `exercicio-09-consumo-combustivel` | Cálculo de consumo médio (km/l) e classificação de eficiência |
| **10** | `exercicio-10-frete` | Regra de negócio para frete grátis ou tarifado com base no pedido |
| **11** | `exercicio-11-pagamento-bonificacao` | Cálculo de remuneração com regras de bônus por produtividade |
| **12** | `exercicio-12-desafio-final` | Cálculo integrado de comissão de vendas e relatório final |

---

## 🚀 Como Executar

Para executar qualquer um dos exercícios:

1. Clone o repositório:
```bash
git clone https://github.com/LucasHtech/atividade-java-faculdade.git
```

2. Acesse a pasta do exercício desejado, compile e execute:
```bash
cd atividade-java-faculdade/exercicio-01-cadastro-simples
javac Main.java
java Main
```
